# LanGuard documentation

The public documentation site uses Docusaurus and is deployed to GitHub Pages.

## Local development

```bash
cd website
npm ci
npm start -- --port 3001
```

Open `http://localhost:3001/LanGuard/`. Changes to pages and styles reload automatically. The local search index is generated by production builds and is intentionally disabled in the hot-reload server to keep development fast.

## Validation

```bash
npm run typecheck
npm run build
```

The production build treats broken documentation links and images as errors. Search is generated locally during the build and does not require an external account.

## Content policy

- Document released functionality only. Keep the private roadmap out of the public site.
- The site describes the latest release and is not versioned initially.
- Root `CHANGELOG.md` is the single source for release notes. `npm start` and `npm run build` generate the documentation page automatically.
- Update documentation in the same pull request as user-facing product behavior.
